# 2～3 周开发计划

估算每天 3～5 小时、约 15 个工作日。两周版本优先核心流程，第三周用于管理端补齐和稳定演示。

## 第 1 周：基础和学生流程

| 天 | 工作 | 交付 |
|---|---|---|
| 1 | 确认设计/包结构/API，建立 Git 基线 | 约定清晰 |
| 2 | Spring Boot、配置、统一响应异常、数据库连接 | 后端启动 |
| 3 | 建表/演示数据，注册登录、BCrypt、JWT、角色 | 身份鉴权可用 |
| 4 | 分类和菜品查询、搜索、详情；前端骨架 | 浏览闭环 |
| 5 | 购物车 API 与页面 | 可维护本人购物车 |

## 第 2 周：订单与后台

| 天 | 工作 | 交付 |
|---|---|---|
| 6 | 预约校验、事务下单、金额快照、原子扣库存、幂等 | 下单一致性 |
| 7 | 订单列表详情、取消回补、管理员状态流转 | 订单闭环 |
| 8 | 确认取餐、评价与审核 | 评价权限正确 |
| 9 | 分类/菜品管理、库存价格上下架 | 菜单后台 |
| 10 | 订单/用户/评论管理 | 管理端核心完成 |

## 第 3 周：统计与交付

| 天 | 工作 | 交付 |
|---|---|---|
| 11 | 首页、个人中心、热门排行、统计 | 页面闭环 |
| 12 | 表单、加载空态错误态、窄屏适配 | 体验完善 |
| 13 | 权限、库存、状态、价格快照边界检查并修复 | 验收通过 |
| 14 | 演示数据、环境配置、启动及答辩流程 | 可复现演示 |
| 15 | 缓冲、整理 README/Git 状态 | 稳定交付 |

## 优先级和验收

必须完成：认证授权、浏览、购物车、事务下单扣库存、订单状态取消、管理员菜品/订单处理、价格快照。其次评价审核、统计、用户管理和视觉细节。落后时减少动效、图表和个人资料编辑，不删服务端算价、库存事务及归属校验。

验收场景：学生访问管理接口为 403；未登录受保护接口为 401；库存不足下单整体回滚；复用幂等键不重复下单；取消只回补一次；改价不改变历史快照；未完成订单不能评价，待审评论不可公开。

## 下一阶段

先创建数据库初始化脚本和不含秘密的配置示例，再初始化 Spring Boot 与 Vue 工程骨架，按第一周推进最小可启动闭环。数据库密码与 JWT 密钥仅存本机未跟踪配置或环境变量。
